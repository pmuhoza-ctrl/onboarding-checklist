# onboarding-checklist

An interactive commissioning checklist for device provisioning across three deployment modes: KK only, Cumulosity only, and Dual endpoint.

## Features

- Step-by-step checklists for each provisioning mode
- Progress tracking with a visual progress bar
- Checks saved automatically — progress persists after closing the browser
- Remembers which mode you were last using
- Works offline after the first load
- Reset per mode without affecting the others

## Usage

Open the page, select your provisioning mode from the tabs at the top, and tap each step to mark it complete. Your progress is saved automatically in your browser.

## Provisioning modes

| Mode | Description |
|------|-------------|
| KK only | Standard KK provisioning flow |
| Cumulosity only | Full Cumulosity onboarding via KK and Cumu scripts |
| Dual endpoint | Combined KK and Cumulosity with dual radar support |

## Notes

- Progress is stored in your browser's local storage — it does not sync across devices or browsers
